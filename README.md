# Сложно сосредоточиться

Адаптивная страница о внимании и концентрации по макету Яндекс Практикума. Кнопки «День» и «Неон» переключают тему вручную, а «Авто» использует настройки системы. Выбор сохраняется в браузере.

Для локального просмотра откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.
